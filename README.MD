🎨 Archivo 1: index-css.html
¿Qué hace?
Crea un cuadro decorativo usando CSS tradicional con bordes personalizados en cada lado.

Bordes del cuadro:

Lado	Estilo	Color
Superior	Dos líneas horizontales	Dorado (#b8860b)
Izquierdo	Línea vertical sólida	Azul oscuro (#1a3a5a)
Inferior	Línea horizontal delgada	Celeste (#5bc0de)
Derecho	Cuatro líneas verticales separadas	Morado (#7a2a95)
Tamaño del cuadro: 500px × 300px

Fondo: Verde claro (#d1e7bc)


🚀 Archivo 2: index-tailwind.html
¿Qué hace?
Crea exactamente el mismo cuadro pero usando Tailwind CSS (utility-first).

Ventajas de esta versión:

No necesita archivo CSS separado

Usa clases directamente en el HTML

Más rápido de modificar

Equivalencias de colores en Tailwind:

Elemento	CSS original	Tailwind
Fondo	#d1e7bc	bg-[#d1e7bc]
Líneas doradas	#b8860b	bg-[#b8860b]
Línea azul	#1a3a5a	bg-[#1a3a5a]
Línea celeste	#5bc0de	bg-[#5bc0de]
Líneas moradas	#7a2a95	bg-[#7a2a95]
